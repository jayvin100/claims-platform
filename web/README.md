# Claims web app

The Angular frontend, generated with [Angular CLI](https://github.com/angular/angular-cli) version 22.2.5.

## Development server

Start the API first (it listens on `http://localhost:5169`, set in `src/app/api.ts`), then run:

```bash
npm install
npx ng serve
```

Open `http://localhost:4200/` and pick a demo user. The app reloads whenever you change a source file.

## Building

```bash
npx ng build
```

The build goes to `dist/`. Angular tests are out of scope for this assessment, so there is no test runner.
